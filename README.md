# SQL Analizer

Semplice analizzatore di sql scritto in rust e slint

## Indice
Funzionalità
Tecnologie utilizzate

## Funzionalità
per ora può solo leggere i dati contenuti in un database

## Tecnologie utilizzate
Linguaggio: Rust
Database supportati: SQLite
Framework: Slint
Librerie principali: Slint, rfd(per il fileDIalog), rusqlite
Interfaccia: Desktop

## requisiti
Richiede almeno Cargo 1.98.1

## Installazione
1. Clona il repository
git clone https://github.com/PlayerTv9/SQL_Analyzer.git
cd <repository>
